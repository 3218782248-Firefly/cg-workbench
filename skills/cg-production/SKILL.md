# CG 制作

先从当前目标、已认可画面和实际工程判断要改变什么。项目路径、配色、软件参数、个人偏好和采用决定留在项目记录；缺失时补必要信息，不重读整段历史。

从参考提取比例、明暗形状、线条节奏、叠压和表演关系，并考虑参考当时的受光。优先核查现有成熟工具和实际适配缺口，再决定是否自写。

选择能改变下一步判断的小样。静态材质或构图变化使用同条件图；涉及动作、物理、闪烁时看相关动态。风格需要多个耦合部分一起调整时允许整体试改，但不要把组合收益归因为未经分离的单一变量。

保留已认可部分和可回退工程。节点存在不等于参与最终输出；先核对有效连接、数据通道语义、UV/法线和显示变换。用户看不出收益或类似小修反复失败时，重新审查上游输入与路线，不机械加大强度或堆版本。

保存后重开实际工程，按改动影响验证。分别报告执行结果、技术检查、可见收益和采用范围；主动指出明显遮挡、穿插、偏色、身份或主次问题，不把逐处找错留给用户。

正常计算和可重复验证交给本地工具；模型在需要判断或异常时介入。工具结果无法覆盖美术目标时，明确剩余观察，不用检查数量代替完成。
