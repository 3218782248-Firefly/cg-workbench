# CG 产物复核

先核对这次交付对应的真实输入、设置、帧/时间范围及采用基线。复用匹配条件的有效检查，不以过期报告或进程退出码作为完成依据。

技术检查覆盖本次约定的格式、尺寸、帧率、实际解码帧数和音轨；检查实际产物而非仅配置。序列通过不代表有损视频自动通过，编码后也按交付要求验证。

技术、内容、美术和用户采用分别记录。全黑画面可能完全可解码；简单颜色/ROI 检查必须有正常与异常样例及适用范围，不称通用人物检测。检查器的通过条件有明确边界时保留必要的观察。

比较须匹配源时刻、机位、表情、受光、显示变换与像素尺度。局部放大和接触表只证明对应范围；实际未实时审看、未审听或未检查完整区间就明确写出。

关注本轮可能破坏的性质及明显画面错误，包括身份/形状、细线、遮挡、运动连续性和声音。用户指出漏检时，把同一缺陷作为回归样本，并按共用机制找其他受影响处。

记录产物哈希、观察范围、发现、局限与采用决定。未完成观察不能自动标为通过；已有通过结果也不能自动等于用户采用。保留可编辑工程和可重建输入，确认恢复入口实际可用后再按授权清理。
