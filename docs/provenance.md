# 来源、使用状态与署名

来源清单解决事实记录，不能替代资源自己的使用条件。每个依赖分别记录类别、来源链接、版本/提交或文件哈希、作者、许可文件、实际用途、本地修改及交付范围。

建议类别：通用程序/算法、通用节点库、角色专用材质预设、颜色贴图、控制图、模型、动作/表情、镜头、场景、音乐、自制代码/素材。不要把图片数据叫作算法而忽略实际复用，也不要因为节点出现在角色包里就认定算法全由该预设作者创作。

使用状态区分：只查阅、已下载、已加载、已在候选验证、已采用、已撤下。旧成片仍然依赖的资源不能因为新候选替换了就从旧片署名中删除。

`templates/assets.json` 可作为项目账本。它是人工维护的记录格式，不是自动许可证审计。未知作者/许可证明确填 `unknown`，不要猜。公开仓库只打包自己可分发的代码与演示资产；其他资源记录获取方式与环境依赖即可。

本项目的脚本与示例是重新编写的通用实现，没有复制原角色模型、控制图、节点组或外部插件源码。原制作项目的经验只提炼为方法与故障类型。引用成熟工具时保留其版本和出处，避免为减少署名重复实现已有算法。
