# 路线与边界

0.1 聚焦逐帧可恢复执行、实际产物验证、来源清晰的示例和能改变决策的经验。新内容按“是否能减少真实错误或重复劳动”选择，不按功能列表扩张。

下一批候选（尚未实现）：

- 多盘/应用缓存保护和事件通知适配：在保留实际策略的前提下支持不同机器。
- Blender 外链与活动输出依赖审计：解决未声明依赖和误删通用算法的问题。
- 分段长任务适配：复用当前逐帧事务原则，同时减少进程启动开销。
- 内容检查插件接口和经过校准的数据集：先明确每个检查器的适用范围。
- 带音轨的交付契约、音画同步与编码后内容检查。
- 可选 AE/Topaz 适配：有可复现接口与收益时再加入，首版不要求安装。
- 在独立机器/独立使用者的新项目上验证文档和工作流。

当前不是安全沙箱，不自动发现任意应用的全部依赖，不保证强制杀死父进程后无孤儿进程，不自动判断美感或作者许可，也不自动清理历史代次。
