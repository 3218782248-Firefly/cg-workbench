# Changelog

## 0.1.0 — 2026-10-23

Initial prototype: content-addressed render generations, validated per-frame
receipts, resume, bounded storage recovery, process timeout and output locking.
Includes synthetic and Blender examples, optional verified silent H.264 preview,
native-scale comparisons, failure-injection tests, three focused Skills and
workflow/provenance/review templates.

See `docs/validation.md` for actual tested scope; no production-readiness or
universal content/visual validation claim is made.
